产品定位与 SKU 规划

产品名称X-Sense 智能水浸传感器（RF 互联语音·多检测点款）
建议型号TBD
产品定位中高端「会说话的水浸传感器」—— 语音播报为核心，接入 SBS50 基站，与烟感/CO 同网互联
SKU 组合单只 $19.99–24.99（<$25）｜ 基站+3只 $44.99–49.99（$25–50）｜ 基站+4只 $69.99–79.99（$50–100）｜ 基站+5/6只 $109–139（>$100）
目标市场美国（主攻）、欧洲（延续 X-Sense 40.5% 龙头势能）

核心报警能力

语音播报（核心）报警类型（Water leak detected）+ 房间地点（自定义）+ 检测部位（底部/侧面/全部位，由侧面探点带来的增量能力）
警示方式蜂鸣 ≥100dB + 语音播报 + 灯光爆闪 三重本地告警
报警音量≥100 dB @1m；三档可调（静音 / 低 ≈70dB / 高 ≥100dB）
互联报警RF 全屋互联，任一触发全屋同响，基站语音播报出事地点与部位
灯光交互待机呼吸灯（可关）；报警红色爆闪；配网/低电量/故障不同灯效
报警独立性L1 本机独立（不配网、不绑 APP、不接基站也能响）→ L2 RF 互联（不需互联网）→ L3 云端推送。离线、在线、未绑定 APP 均不影响本机与互联报警
静音/复位设备端一键静音；APP 远程静音；水干后自动复位

分区水位检测

探点布局在行业通用的底部探点基础上增加侧面多高度探点（建议低位 ≈8mm、高位 ≈20mm），正反面均可工作
分区判定底部 = 初期渗水/微量；侧面 = 水位确认上升；全部位 = 大面积浸泡
分级报警（可选）默认：任一探点触发即全量报警，以保证灵敏度优先；分级策略作为 APP 内可选设置开放给需要的用户——底部 → 提示级、侧面 → 报警级、全部位 → 紧急级
翻倒容错被冲翻/碰翻后，原侧面探点转为着地面仍可检测
⚠ 工程要求侧面探点需凹槽沉降式防误触与防积灰；双探点同时导通判定 + 短时滤波
⚠ 功能价值备注侧面检测点的实际用户价值不高——该功能本质上做的是判断水灾的严重程度，而用户对水浸传感器的普遍期待是越灵敏越好、越早报警越好，并不需要设备替他们分级。
因此本功能的定位是：在成本基本不增加的前提下，作为竞争差异化功能存在。对外传播主打「更多检测点」（检测点数量与覆盖面），而非「严重程度分级」；分级能力仅作为 APP 内可选设置，不作为主推卖点。

冻结 / 低温预警

功能范围仅做低温阈值触发的及时预警（本地语音提示 + APP 推送）。不做温度曲线、不做温度历史记录、不做温湿度看板
触发逻辑温度低于设定阈值（如 ≤4 ℃ / 39 ℉）时触发一次预警，回温后自动复位；阈值可在 APP 内选择
⚠ 功耗前置约束温度检测频率与是否量产搭载，须由研发评估功耗影响后综合确定——温度采样会直接影响电池寿命，须与「10 年目标 / 至少 5 年」的续航底线一并权衡。若评估结果显示对续航影响超出可接受范围，应优先保证电池寿命，冻结预警可降级为可选配置或后续版本
实现建议低频采样（如每 10–30 分钟一次）而非连续监测；仅在接近阈值时提高采样率，兼顾预警及时性与功耗
